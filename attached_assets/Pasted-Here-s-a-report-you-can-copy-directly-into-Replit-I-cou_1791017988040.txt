PIXL Sports: Premium Hype Card Design Report

Goal

Evolve the existing Hype Card into a personalized, collectible athlete design that parents enjoy creating, sharing, and saving.

The premium value should come from the finished artwork and matching exports: a professional-looking card featuring their own athlete, customized to their team and season.

Video upload and playback have been removed. This proposal focuses on photos, layered graphics, and optional AI-assisted backgrounds.

1. Improve the existing card

The current card has a strong foundation: a large athlete photo, bold name, and a recognizable sports-card frame.

The next version should introduce more depth and personalization:

* Isolate the athlete from the original photo background.
* Place the athlete over a designed sports background.
* Allow the athlete’s head, ball, or equipment to overlap selected graphic layers.
* Use team colors throughout the background, border, and accents.
* Add optional jersey number, position, team badge, and season.
* Reduce the prominence of the generic “HYPE CARD” label so the athlete’s identity leads.

Keep the original full-photo style available. Background removal will not work equally well for every photo.

Example using Kimberly’s card

Create a Signature version with:

* A deep navy background and restrained pink accents inspired by her jersey.
* Oversized “KIMBERLY” lettering partly behind her head.
* The soccer ball overlapping an inner graphic border.
* A small Hurricanes badge.
* Optional number and position.
* A subtle “FALL 2026” season label.

Preserve Kimberly’s actual appearance and uniform.

2. Proposed design collections

Collection	Visual direction	Purpose
Signature	Athlete cutout, oversized name, team colors, layered border, subtle stadium background	Main premium athlete card
Chrome	Metallic frame, restrained holographic accents, embossed-looking typography	Collectible trading-card feel
Spotlight	Dark background, stadium lighting, team-colored glow, minimal typography	Dramatic athlete introduction
Editorial	White or cream background, bold typography, clean photo layout, small season details	Sports magazine appearance
Milestone	Achievement-focused headline, date, photo, coordinated celebration accents	First goal, personal best, tournament, or season finale

Start with Signature, Chrome, and Spotlight. Add Editorial and Milestone after validating interest.

Each collection should remain readable and recognizable on a phone. Avoid excessive decoration.

3. AI and background workflow

No custom AI model training is required.

Treat background removal, background generation, and final card composition as separate tasks.

Recommended first-release workflow

1. Parent uploads a photo.
2. Parent chooses full-photo mode or athlete cutout mode.
3. Background removal produces a transparent athlete image.
4. Parent selects a design collection and background.
5. Parent chooses team colors and adjusts the photo’s position and scale.
6. The application combines the photo, background, text, and graphics.
7. Parent saves, shares, or downloads the result.

Preserve the original athlete photo. Avoid generative changes to the athlete’s face, body, jersey, hands, or equipment.

Provide an original-photo fallback if the cutout is unsatisfactory.

Start with reusable backgrounds

Create a curated collection of backgrounds once, then reuse them across cards:

* Stadium lights.
* Team-color gradients.
* Spotlight haze.
* Chrome textures.
* Subtle sport-specific environments.

Apply team-color variations using controlled overlays or theme settings where practical. Switching between existing backgrounds should not trigger another AI request.

This approach gives parents immediate previews and makes costs easier to manage.

Optional later feature: custom backgrounds

Offer limited custom background generation from guided choices:

* Sport.
* Team colors.
* Style.
* Light or dark appearance.

Generate the background separately, without sending the athlete photo when it is unnecessary. Save successful backgrounds so they can be reused.

Keep names, numbers, badges, and other exact text in the application’s layout system rather than asking AI to draw them.

4. Separate the artwork from its controls

Provide two presentations of the same card:

Interactive card view: Shows the artwork with access to Replies, Stats, Taps, Events, and existing card interactions.

Clean artwork export: Contains the athlete design and selected identity details, without navigation buttons, flip instructions, or other interface controls.

Move the navigation controls outside the artwork boundary where practical. Preserve the current card’s functionality and sharing permissions.

5. Matching designs create more premium value

A premium collection should produce coordinated formats from the same athlete information and theme.

Format	Parent use
Athlete card	Share digitally or save as a keepsake
Phone wallpaper	Keep their athlete on their phone
Game-day graphic	Share the upcoming event
Printable poster	Display at home or bring to a game
Milestone graphic	Celebrate a specific achievement

Start with the athlete card and one matching export. Expand once the design system works reliably.

Use dedicated layouts for each format rather than stretching one image into every size.

6. Mobile creation experience

Keep the editor simple:

1. Choose a look — collection previews.
2. Add your photo — upload, cutout option, crop and positioning.
3. Make it yours — colors and optional athlete details.
4. Save and share — clean preview and export options.

Show the actual card prominently while editing. Parents should enjoy seeing their design take shape.

Use sensible defaults from existing athlete data and remember their selections. Optional details should disappear cleanly when omitted.

7. Suggested premium structure

This is a product hypothesis to test, not a finalized pricing decision.

Basic access could include:

* Existing full-photo card.
* A small selection of standard designs.
* Basic sharing and current card interactions.

Premium access could include:

* Signature, Chrome, and Spotlight collections.
* Athlete cutouts and advanced layering.
* Expanded backgrounds and customization.
* High-resolution downloads.
* Matching wallpapers and posters.
* Later, a limited allowance of custom AI backgrounds.

The paid promise should emphasize the finished result: personalized sports artwork featuring their athlete.

8. Implementation requirements

Build on the existing card system after inspecting its structure.

* Store the original photo, processed cutout, background selection, athlete placement, and design settings separately.
* Use a shared design specification for the editor, saved card, and export renderer.
* Keep text and layout deterministic.
* Ensure exports reproduce the approved preview.
* Cache successful cutouts and generated backgrounds.
* Run costly processing only after an explicit user action.
* Keep provider credentials and paid API calls on the server.
* Enforce premium access and generation limits on the server.
* Handle loading, failure, retry, and original-photo fallback states.
* Preserve existing sharing access controls.
* Keep the card usable without animation; support reduced-motion preferences for optional Chrome effects.

Before selecting a processing provider, report its current pricing, photo-handling terms, expected processing time, and integration requirements. Do not assume all AI image operations have the same cost.

9. Recommended build phases

Phase 1: Design prototype

Build Signature, Chrome, and Spotlight previews using curated backgrounds. Establish layered composition and clean artwork exports.

Phase 2: Photo processing

Integrate background removal, saved cutouts, placement controls, and graceful fallbacks.

Phase 3: Premium package

Add matching exports and connect premium access to the existing subscription system.

Phase 4: Optional custom generation

Add limited custom AI backgrounds only after evaluating demand, output quality, and costs.

10. Acceptance criteria

The initial release is ready when:

* Each collection looks distinct and polished on mobile.
* The athlete’s original appearance remains intact.
* Parents can adjust a cutout without clipping important details.
* Names of different lengths and missing optional fields display correctly.
* Changing curated backgrounds does not make a new AI request.
* Failed processing leaves the original photo usable.
* Saved designs reopen accurately.
* Downloads match the preview and exclude interface controls.
* Existing interactions and sharing permissions still work.

First implementation priority: deliver a polished Signature card with athlete cutout, team-color background, layered name treatment, and a clean downloadable version.
