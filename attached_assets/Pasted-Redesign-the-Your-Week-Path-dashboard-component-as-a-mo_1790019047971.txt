Redesign the “Your Week Path” dashboard component as a modern, connected four-stage sports journey.

Do not use four separate outlined square buttons. The four stages should visually connect and read as one continuous progression through game week.

DESKTOP LAYOUT

Create one wide panel with:

* Deep navy background: #0B1F3A
* Rounded 20px corners
* Soft blue border and shadow
* Very subtle stadium-light, field-line, or halftone texture
* Comfortable internal padding

Header:

YOUR WEEK PATH

Supporting text:

Follow each step as game day moves closer.

Create four equal connected segments:

1. PLAN THE WEEK
   Calendar icon

2. PREP
   Checklist icon

3. CAPTURE THE GAME
   Activity or pulse icon

4. SEND THE HYPE
   Lightning icon

Use angled or chevron-shaped edges between segments so they appear connected. Place a thin horizontal progress line behind the step indicators.

COMPLETED STATE

* Blue circular badge with a white checkmark
* Dark blue tinted segment background
* Small electric-blue “COMPLETE” label
* Completed segments remain clickable
* Avoid green and pink outlines

CURRENT STEP

The current recommended stage must be visually dominant:

* Raise it slightly above the other stages
* Use an electric-blue-to-violet gradient
* Add a subtle blue glow
* Display the stage number inside a white-outlined circle
* Use a white stage icon
* Add a small orange “UP NEXT” pill
* Apply a restrained pulse animation when the dashboard first loads

The current stage must be driven by the existing schedule and recommendation logic. Do not permanently hardcode Step 4 as active.

COLORS

* Deep navy: #0B1F3A
* Electric blue: #2878F5
* Bright blue: #55A4FF
* Violet accent: #7847F7
* Game-day orange: #FF6433
* White: #FFFFFF
* Muted text: #9FB0C8

INTERACTION

* Entire stage segment should be clickable
* Add a slight upward movement and brighter border on hover
* Include visible keyboard focus styles
* Use smooth 180–220ms transitions
* Respect prefers-reduced-motion
* Completed steps should remain accessible so users can return to earlier tools

MOBILE LAYOUT

Do not shrink all four desktop segments into four tiny boxes.

On mobile:

* Show a compact horizontal stepper across the top with four connected circles
* Completed circles contain checkmarks
* The active circle contains the stage number and receives the blue glow
* Display abbreviated labels beneath the circles: Plan, Prep, Capture, Send
* Under the stepper, show one full-width detail card for the current recommended stage
* The detail card contains the icon, full stage name, short explanation, status, and primary action button
* Users can tap another step to replace the detail card with that stage
* Keep the component within the page width without horizontal overflow

STYLE GOAL

The component should feel like a premium consumer sports app for parents and supporters: energetic, modern, clear, and approachable. It should coordinate visually with the new blue PIXL Sports hero banner without becoming a futuristic gamer or industrial interface.
