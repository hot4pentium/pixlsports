# Before Game Day — revision script

## Treatment

**Promise:** Keep the weekly plan, event, checklist, and ready moment in one clear season flow.  
**Identity:** Existing Pixl Sports palette and Barlow Condensed / DM Sans pairing.  
**Hero:** A phone interface that turns a schedule into a shareable event card and a ready-to-go checklist.  
**Motion:** Masked type, phone-scale reveals, and card-to-card visual handoffs.  
**Arc:** Season promise → weekly plan → one legible event card → checklist → resolved ready state.  
**Payoff:** The final completed checklist resolves the film's active interface into a calm, branded sign-off.
