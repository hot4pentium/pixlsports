---
name: Immersive Athlete Locker
description: User-approved direction for the dedicated Pixl Sports Athlete Locker.
---

Build a responsive Locker inspired by the user's supplied cinematic locker image as the athlete's visual centerpiece within the signed-in dashboard. Populate it with live selected-athlete data and use it to access Event Cards, Stat Tracker, and Prep. Preserve the existing account and permission model; do not add an Owner/Supporter role switch.

Equipment should appear as automatic rewards for meaningful return and usage milestones—such as distinct returns, first/tenth Event Cards, and first/fifth completed Stat Tracker games—instead of collecting badges.

**Why:** The user chose a full Locker experience based on the reference image, then clarified that it may be the primary surface and that equipment should replace badges as product-use milestones.

**How to apply:** Treat the image as the Locker's visual reference and preserve Pixl Sports' existing identity around it. Count only successful, durable actions; do not reward refreshes, drafts, edits, retries, failed saves, or abandoned tracker sessions. Keep card and parent-management permissions as they are.

Parents are expected to build the athlete's site, while the athlete should be involved in making it their own.

**Why:** The user said the parent will basically build the site but wants to involve the student.

**How to apply:** Make athlete participation part of the parent-led creation and personalization flow without changing the existing account and permission model.

Keep the dashboard geared toward leading parents through the week when integrating the Dynamic Showcase and Locker presentations. Athlete expression must complement, not replace or bury, the parent’s weekly guidance.

**Why:** The user approved combining the designs only as long as the dashboard continues leading parents through the week.

**How to apply:** Preserve the existing weekly recommendations and preparation/game-day/celebration actions; keep them prominent on phones as well as desktop.
