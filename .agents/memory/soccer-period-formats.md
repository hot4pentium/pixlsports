---
name: Soccer period formats
description: Compatibility rule for soccer period choices across Stat Tracker and Game On.
---

New live soccer games should ask whether the competition uses halves or quarters before recording plays. Older soccer games that have no saved period choice remain half-based, rather than asking again or reinterpreting their existing event numbers.

**Why:** Prior soccer tracking labeled periods as halves. Requiring a new choice on restored historical games would interrupt ongoing sessions, while silently changing their labels could misdescribe recorded plays.

**How to apply:** Preserve explicit format choices through local saves, cloud history, and live supporter views. Treat a missing legacy choice as halves; reserve an explicit pending choice for newly started games that still need setup.
