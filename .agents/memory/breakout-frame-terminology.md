---
name: Breakout frame terminology
description: Distinguish the unwanted blue wrapper from the metallic card outline in user requests.
---

Remove the blue outer rectangle from Breakout cards; preserve the full rounded metallic artwork outline and navigation below the card.

**Why:** The user repeatedly distinguished the unwanted blue rectangle from the metallic outline. Rounding or restoring the blue wrapper was not the intended result.

**How to apply:** Treat references to the blue rectangle as the surrounding presentation wrapper, not as a request to remove the metallic SVG outline or restore an inset photo-window border.
