---
name: Completed Event sharing
description: Which card the owner shares after an event finishes.
---

After an event ends, its Share action should share the athlete's HYPE Card, not the Event Card. Upcoming and live events retain Event Card sharing.

**Why:** The user requested HYPE Card sharing from the Event Card after the event is over.

**How to apply:** Respect explicit completed game records as well as the event's completed stage. Never publish a private HYPE Card implicitly; direct owners to manage sharing if the card is private, expired, or unavailable.
