---
name: Supporter profile propagation
description: Sets the boundary between profile defaults and authored sports content.
---

Supporter profile athlete details should automatically seed new or local fan-tool work and live dashboard views. Do not silently rewrite explicitly saved cloud designs or already-published share snapshots when the profile changes.

**Why:** The profile is the user’s reusable starting point, while saved and published content may represent a deliberate past design or a different game.

**How to apply:** Read the normalized supporter profile at tool entry, apply it to blank or newly opened local drafts, and preserve authored cloud/share data unless the user explicitly edits it.
